Usage: bal discover <noun> [<name> ...] [-p <org>/<name>[:<version>]]
                    [--client|--class|--service <name>] [--output json|text]
                    [--filter <keyword>] [--page <n>] [-m <module>] [--refresh]

Read a Ballerina package off Central. A signature from here is the source for what
compiles; a readme, a web search and a remembered API are not.

Nouns:
  package <org>/<name>[:<version>]   A package's overview.
  search <keyword> ...               Central's packages and symbols, or with -p
                                     every name in one package.
  client [<name>]                    The clients, or one client's members.
  service [<name>]                   The service types, or one with what a service
                                     of it implements.
  class [<name>]                     The classes, or one class's members.
  function [<name>]                  The module's functions, or one function's
                                     signature.
  type [<name>]                      Every type, or one declaration.
  method [<name>]                    A container's methods, or one method's
                                     signature.
  resource [<path> [<accessor>]]     A container's resource paths, or one resource
                                     method's signature.
  readme [<n>|"<title>"]             The readme, or one section of it.

A name means one thing; no name, a listing. Every noun but package takes the package
with -p; search takes it only to search one package. Flags may come before the noun
or after it.

Typical session:

  1. Find a package or a symbol:  bal discover search kafka send
  2. What a package offers:       bal discover package ballerinax/kafka  (or bal discover ballerinax/kafka)
  3. Find a name inside it:       bal discover search send -p ballerinax/kafka
  4. One call, fully addressed:   bal discover method send -p ballerinax/kafka --client Producer
                                  bal discover resource gists/public get -p ballerinax/github \
                                      --client Client
  5. Its container, left out:     bal discover method send -p ballerinax/kafka
  6. A record, enum or error:     bal discover type ConnectionConfig -p ballerinax/github
  7. One specific version:        bal discover client Client -p ballerina/http:2.15.7

With no version after the package, the one your project's Dependencies.toml locks is
read (found from the current directory up), else Central's latest.
Exit codes: 0 an answer (an empty search or --filter too), 1 not found (a package,
name or page), 2 a usage error, 3 ambiguous (the matches are listed), 4 Central
unavailable for now (retry later), 5 an answer from Central a retry will not change,
6 an internal error.
Run `bal discover <noun> --help` for one noun's names, flags and examples.

  -p, --package <org>/<name>[:<version>]   The package to read, as bal pull names
                                           it. With no version, the one your
                                           project's Dependencies.toml locks, else
                                           Central's latest.
  --client|--class|--service <name>        The container that declares a method or
                                           resource, for method and resource only:
                                           one at most, left out when exactly one
                                           container declares it.
  --output json|text                       Override the TTY-detected default: human
                                           text at an interactive terminal, JSON
                                           otherwise.
  --filter <keyword>                       Narrow a listing to entries whose name,
                                           path, parameter or type matches this
                                           keyword. Filtering is local; nothing is
                                           sent to Central. On package it searches
                                           the package's names, as search does.
  --page <n>                               Show page <n> (counting from 1) of a
                                           listing longer than 40 entries. A page
                                           past the last one, or against an answer
                                           that has only one page, is an error.
  -m, --module <module>                    Target this submodule instead of the
                                           package's default module, the same
                                           everywhere including readme. The
                                           submodule's name only (for example
                                           httpscerr), not <org>/<name>.<submodule>.
  --refresh                                Ignore any cached copy and rewrite it.
                                           Worth passing only when a name should
                                           exist and does not.
