Read a Ballerina package's API off Central; trust it over memory or the web

Usage: bal discover <noun> [<name>] -p <org>/<name>[:<version>] [options]
       bal discover package <org>/<name>[:<version>] [options]

Commands:
  package <org>/<name>[:<version>]  a package's overview
  search <query>                    search Central, or one package with -p
  client [<name>]                   the clients, or one client's members
  service [<name>]                  the service types, or one and its methods
  class [<name>]                    the classes, or one class's members
  function [<name>]                 the functions, or one function's signature
  type [<name>]                     every type, or one declaration
  method [<name>]                   a container's methods, or one's signature
  resource [<path>]                 resource paths, or one method's signature
  readme [<n>|"<title>"]            the readme, or one section of it
  Every noun but package needs -p; search takes it only to search one package.
  bal discover <org>/<name> is short for bal discover package <org>/<name>.
  Options may come before or after the noun.
  Run 'bal discover <noun> --help' for a noun's options and examples.

Options:
  -p, --package <org>/<name>[:<version>]
                              read this package, as bal pull names it
  --accessor <accessor>       name the resource method of the path, e.g. get
  --client|--class|--service <name>
                              name the container of a method or resource
  --filter <keyword>          narrow a listing to the names that match a keyword
  -h, --help                  print this help
  --module <name>             read this submodule by name, e.g. httpscerr
  --output-format json|text   set the format (default: text on a TTY, else json)
  --page <n>                  show page n, 40 entries a page (default: 1)
  --refresh                   refetch when a name should exist but is not found
  -V, --version               print the tool's version

Examples:
  # Find a package or a symbol on Central
  bal discover search "kafka send"
  # What a package offers
  bal discover package ballerinax/kafka
  # A method's signature, its container named
  bal discover method send -p ballerinax/kafka --client Producer
  # A resource method's signature: its path, then its accessor
  bal discover resource gists/:gistId/star -p ballerinax/github --accessor put
  # A record, enum or error
  bal discover type ConnectionConfig -p ballerinax/github
  # One version; without one, ./Dependencies.toml's lock, else the latest
  bal discover client Client -p ballerina/http:2.15.7
